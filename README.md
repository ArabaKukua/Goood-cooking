# Goood Cooking — West African Dishes Website Prototype

**UX/UI Design Case Study | Araba Adenu-Mensah, UX/UI & Graphic Designer, Lethbridge, AB**

Goood Cooking is a prototype of a cooking website for local West African dishes, making it easier to discover and cook dishes from the region.

- **My role:** UX/UI Designer
- **Focus:** Food discovery, clear recipe presentation, and a welcoming website experience
